# Design Bible

Purpose
- Capture UI/UX guardrails and design-system direction for Konpuk v1.0.

Scope
- Visual consistency, accessibility, and frontend experience principles.

Prerequisites
- Understanding of the current React frontend routes and components.

Instructions
## Design Principles
- Prioritize usability and clarity for marketplace flows.
- Preserve mobile-first behavior and responsive layouts.
- Keep branding and typography consistent across pages.

## Accessibility
- Maintain semantic HTML and keyboard navigability.
- Ensure adequate color contrast and readable type sizes.

## Content and Interaction
- Keep error messages actionable.
- Avoid unnecessary UI complexity in critical flows (login, posting, checkout-like interactions).

Verification
- Frontend pages render consistently across core routes.

Troubleshooting
- If a design inconsistency appears, document it in pull request notes and align implementation with this guide.
